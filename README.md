# TRPG サポートサービス

テーブルトークRPGを遊ぶ際に、スマートフォンを利用して、
ゲームマスタのサポートを行う機能を提供するサービスです。

## ダイス共有機能
- 公開ロールおよびGMとのみの共有機能

## キャラクターシート管理機能
- アカウントを作るとキャラクターシートを管理できる機能
- 特定のPLの数値をGMから変更できる機能
- GMで情報をマスクすることが出来る機能

## GMからの通知機能
- GMから特定のPLにテキストメッセージを送る機能

## マップ共有機能
- マップを共有できる機能

## グリッドマップ機能
- 戦闘時にキャラクターの位置情報を共有する機能
- 表示倍率を変えられる機能

## 演出
- GMが参加者もしくは特定のPLのスマホで、効果音もしくはバイブレーションを鳴らす機能
